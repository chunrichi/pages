# 01 · 设计系统

> 目标：浅色、克制、为信息让路。所有界面共用同一套 token 与组件；颜色只表达状态，动效只解释变化。  
> 代码即规范：[`assets/tokens.css`](../assets/tokens.css) · [`assets/base.css`](../assets/base.css) · [`assets/components.css`](../assets/components.css)

## 1. 设计原则

1. **纸张与墨**：暖灰纸底、纯白表面、近黑文本。没有大面积渐变、玻璃拟态只用于浮层。
2. **一条分隔线胜过一组边框**：优先用 1px hairline 组织信息，阴影只用于浮起与层级。
3. **状态必须有文字**：状态点、颜色只是辅助；色盲用户不依赖颜色也能读。
4. **动作只有一个主按钮**：一屏最多一个实心主操作；其余用描边或文字。
5. **动效服务理解**：进入、推进、失败三种变化才使用动效；不装饰、不无限循环（live 指示除外）。

每种语义色包含 `主色 / 深色 / tint / line` 四档：

| 语义 | 主色 | Tint | 使用场景 |
| --- | --- | --- | --- |
| **Blue · 主色** | `#2D5BE3` | `#EDF1FE` | 交互、链接、当前阶段、焦点 |
| **Teal · AI** | `#0B8F7C` | `#E7F6F2` | AI 生成、Agent、运行中、知识库 |

| **Violet · ChaRM** | `#6657D8` | `#F0EDFD` | ChaRM、Change Request、版本 |
| **Green · 成功** | `#1D825A` | `#E9F5EF` | 已通过、已同步、完成 |
| **Red · 异常** | `#C53F3F` | `#FBECEC` | 失败、死信、驳回、危险操作 |

> 规则：**一个视图内语义色不超过 4 种**。工程信息（JIRA / SolMan / Teams）保留少量品牌色，但只出现在来源标签，不参与状态表达。

## 3. 字体

```css
--sans: -apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC",
        "HarmonyOS Sans SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
--mono: "SF Mono", ui-monospace, SFMono-Regular, "JetBrains Mono", Menlo, monospace;
```

| 角色 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| Display | 44–64 / 1.08–1.12 | 660 | 仅展示页 Hero |
| H1 | 26 / 1.2 | 650 | 页面标题 |
| H2 | 20 / 1.3 | 640 | 区块标题 |
| H3 | 16 / 1.4 | 630 | 卡片标题 |
| Body | 14 / 1.55 | 400–500 | 正文、表格 |
| Small | 12.5 / 1.55 | 400–500 | 辅助信息 |
| XS | 11.5 | 500 | 标签、元数据 |
| Micro | 10.5 | 550 | 全大写 eyebrow / 列头 |
| Mono | 10–12 | 500–600 | ID、时间、路径、数字 |

**排版细节**

- 中文标题字距 `-0.02em ~ -0.04em`；正文不加字距。
- 数字统一 `font-variant-numeric: tabular-nums`，用于表格、指标、ID。
- 全大写 + `letter-spacing: .12em` 只用于分区标签（`eyebrow`、列头），不用于正文。
- 段落最大宽度：正文 640–720px；文档 620–760px。

## 4. 间距与栅格

4px 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72 / 104`。

| 场景 | 值 |
| --- | --- |
| 应用外壳内边距 | 32px（移动端 18px） |
| 卡片内边距 | 18–24px |
| 卡片间距 | 12–16px |
| 表单字段间距 | 14–16px |
| 页面区块间距 | 28–40px（展示页 104px） |
| 页面最大宽度 | 1320px |

**Web 应用栅格**

- 侧栏 232px；顶栏 60px。
- 内容区：`1fr`；详情页 `1fr + 296–322px`（主内容 + 上下文栏）。
- 列表页：全宽卡片；看板 6 列，每列最小 168px，横向滚动。
- 表单页：`1fr + 306px`（表单 + 辅助面板），窄屏降级为单列。

## 5. 圆角、阴影与描边

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-xs` | 5px | 标签、小按钮 |
| `--r-sm` | 7px | 按钮、输入框、树节点 |
| `--r-md` | 10px | 列表卡、弹层 |
| `--r-lg` | 14px | 主卡片 |
| `--r-xl` | 18px | 大面板 / 展示区 |
| `--r-full` | 999px | 状态 pill、头像 |

阴影只三档：

```css
--shadow-1: 0 1px 2px rgba(22,24,28,.04), 0 1px 3px rgba(22,24,28,.03);
--shadow-2: 0 2px 6px rgba(22,24,28,.04), 0 12px 32px -12px rgba(22,24,28,.14);
--shadow-3: 0 24px 64px -20px rgba(22,24,28,.22);
```

- 卡片默认 `shadow-1`；hover 用 `shadow-2`；抽屉 / 弹窗 `shadow-3`。
- 1px `--line` 是主要层级手段；**不要**用双边框或大量阴影堆叠。

## 6. 图标

- 线性图标，24×24 viewBox，`stroke-width: 1.6`，圆角线帽。
- 默认 14–16px；小按钮 12–13px；空状态 18px。
- 图标不单独承载语义：必须配文字或 `aria-label` / tooltip。
- 图标集：[`assets/icons.js`](../assets/icons.js)（约 120 个内联 SVG，无外部请求）。

## 7. 组件规范

### 7.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | 墨色实心（或蓝色实心） | 页面唯一主操作 |
| Secondary | 白底描边 | 次要动作 |
| Ghost | 无底无框 | 取消、次级链接 |
| Danger | 红字 / 红描边 | 驳回、解除绑定 |
| Small | 28px / 10–11px | 表格与卡片内操作 |
| Icon | 32×32 | 图标动作，必须有 tooltip |

状态：hover 变浅底、active 下移 0.5px、loading 用中心 spinner 替换文字、disabled 45% 透明且不可点击。

### 7.2 状态标签（Pill）

```
● 已通过    ● 待确认    ● 进行中    ● 失败    ● 待上线
```

- 高度 22px（大号 26px），圆角 full；背景 tint + 深色文字 + 6px 圆点。
- 状态文字用业务语言（「待确认」而不是 `in_review`）；工程状态可在 tooltip 中给出。
- 同一语义在任何页面使用同一颜色，例如「待确认」永远是 amber。

### 7.3 输入与表单

- 高度 34px（大号 40px），圆角 7px，边框 `--line-2`。
- 焦点：蓝色描边 + 3px 蓝色 tint 外发光；错误：红色边框 + 不可只靠颜色，附文字。
- 标签与控件间距 6px；支持 hint / 字符计数 / 必填星号。
- 多选负责人：选中 chip + 可搜索下拉；chip 可单独移除。

### 7.4 卡片

- 白底、1px 边框、14px 圆角、`shadow-1`。
- 结构固定：`card-head`（标题 + 动作）→ `card-body` → 可选 `card-foot`（次级信息，浅底）。
- 点击整卡跳转时，hover 位移不超过 1px，边框加深，箭头右移 2px。

### 7.5 表格

- 表头：10.5px 全大写、`--ink-3`、`--surface-2` 底、底部 1px 线。
- 行高 44–56px；hover 用 `--surface-3`；选中行用 `--blue-tint`。
- 强字段用 570 字重 + `--ink`；ID / 时间 / 数值用 mono。
- 一行只放一个主链接；其余动作收进「更多」。

### 7.6 阶段推进器

| 变体 | 用法 |
| --- | --- |
| `stepper`（横向 6 步，带节点与说明） | 需求详情顶部 |
| `stage-rail`（6 段细条） | 列表行、卡片内 |
| `wizard-steps`（带编号与副标题） | 新建需求 |
| `progress`（单条） | Agent 运行、队列数值 |
| `ring`（环形） | 单个百分比（预留） |

规则：已完成 = 墨色实心 + 勾；当前 = 蓝色 + 呼吸点；未来 = 线框 + 灰字。推进动画只播一次（进入页面时），不循环。

### 7.7 文档评审

- 文档正文 12.5–14px，行高 1.75；H2 17–19px，带 hairline 上分隔。
- 行内批注：琥珀色下划线 + 数字 pin；点击联动右侧批注卡。
- 版本对比：`ins` 绿色底、`del` 红色删除线；只显示差异段，不做整页红色。
- 门禁检查：`is-ok` 绿、`is-warn` 琥珀；在门禁条里显示「检查通过 2/3」而不是只显示色块。

### 7.8 图表与监控

- 折线：1.5px 描边，无网格；面积填充 50% tint。
- 迷你进度条：3–5px 高，圆角 full。
- 队列指标：数值 + 单位（小号）+ 一句趋势说明；不要只用红绿。
- Live 指示：小圆点脉冲 + 文字（`运行中` / `实时` / `在线`），1.8–2.4s 周期。

### 7.9 浮层

| 类型 | 规范 |
| --- | --- |
| 通知抽屉 | 460px；标题 + tabs + 列表 + 底部设置入口 |
| 详情抽屉 | 620px；用于工单 / 队列 / 调用详情 |
| 命令面板 | 620px，置顶 12vh；输入 + 分组结果 + 键盘提示 |
| 确认弹窗 | 520px（宽 680px）；标题 + 说明 + 主体 + 右对齐按钮 |
| Toast | 墨色底，居中底部，2.4s 自动消失；只用于操作确认 |

遮罩：`rgba(22,24,28,.26)` + 2px 模糊；抽屉/弹窗出现 220–360ms。

## 8. 动效

| Token | 时长 | 用途 |
| --- | --- | --- |
| `--dur-1` | 140ms | hover、按钮按压 |
| `--dur-2` | 220ms | 展开、颜色变化 |
| `--dur-3` | 360ms | 抽屉、弹窗、页面淡入 |
| `--dur-4` | 560ms | 区块入场、数字滚动 |
| `--dur-5` | 900ms | 阶段线绘制、进度填充 |

- 主缓动：`cubic-bezier(.22,.72,.24,1)`；弹性只用于成功勾选 / switch。
- 进入：`opacity 0→1 + translateY(8–16px)`；同屏多个元素按 38–45ms 交错。
- 数字：900ms ease-out 计数；进度条：1.2s；阶段线：900ms 从左到右。
- **不要**：无限旋转（loading 例外）、弹跳、彩虹渐变、滚动劫持。
- `prefers-reduced-motion` 下全部时长降为 0，内容直接可见。

## 9. 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1180px | 完整双栏 / 三栏 |
| 960–1180px | 侧栏保留 232px；详情侧栏下沉为两列；看板横向滚动 |
| ≤ 960px | 侧栏变为抽屉（顶栏菜单按钮）；隐藏次要列；内边距 18px |
| ≤ 640px | 单栏；表格横向滚动；抽屉全宽；字体缩小一档 |

原则：**先隐藏辅助信息，不隐藏操作。** 表格在窄屏可以横向滚动，不折叠成卡片迷宫。

## 10. 可访问性

- 正文对比度 ≥ 4.5:1；辅助文本至少 3:1；不使用纯色块承载唯一含义。
- 所有交互控件有可见 focus ring（2px 蓝 + 2px offset）。
- 图标按钮必须有 `aria-label`；状态变化通过 `aria-live="polite"` 区域播报。
- 表单标签与控件用 `for/id` 关联；错误信息紧邻字段。
- 键盘：`⌘K` 命令面板、`Esc` 关闭浮层、`Tab` 顺序符合视觉顺序、命令面板支持 ↑↓/Enter。
- 尊重 `prefers-reduced-motion`；不使用纯手势操作。

## 11. 实现约定

- 所有颜色、字号、间距、圆角、时长均通过 CSS 变量引用，禁止在页面内写死色值（演示数据中的品牌色除外）。
- 组件类名采用 `block__element--modifier`，状态类 `is-*`（`is-active` / `is-done` / `is-current` / `is-open`）。
- 页面级样式放在 `assets/app.css`（按页面注释分区）；VSCode 模拟器与展示页各自独立 CSS。
- 新增页面时优先复用 `.page-head`、`.card`、`.pill`、`.table`、`.stepper`、`.drawer` 等基础结构，不另起一套。

## 12. 设计走查清单

- [ ] 页面只有一个 Primary 按钮
- [ ] 状态都有文字，不只靠颜色
- [ ] 表格 ID / 时间 / 数字使用 mono
- [ ] 卡片没有多余边框和阴影
- [ ] 长文本行宽 ≤ 760px
- [ ] 空状态给出下一步动作
- [ ] 失败信息说明「现在该做什么」
- [ ] 所有浮层可 Esc 关闭
- [ ] 减少动效模式下内容完整
- [ ] 窄屏关键操作仍可达

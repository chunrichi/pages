# 01 · 设计系统

> 目标：浅色、克制、为信息让路。所有界面共用同一套 token 与组件；颜色只表达状态，动效只解释变化。  
> 代码即规范：[`assets/tokens.css`](../assets/tokens.css) · [`assets/base.css`](../assets/base.css) · [`assets/components.css`](../assets/components.css)

## 1. 设计原则

1. **纸张与墨**：暖灰纸底、纯白表面、近黑文本。没有大面积渐变、玻璃拟态只用于浮层。
2. **一条分隔线胜过一组边框**：优先用 1px hairline 组织信息，阴影只用于浮起与层级。
3. **状态必须有文字**：状态点、颜色只是辅助；色盲用户不依赖颜色也能读。
4. **动作只有一个主按钮**：一屏最多一个实心主操作；其余用描边或文字。
5. **动效服务理解**：进入、推进、失败三种变化才使用动效；不装饰、不无限循环（live 指示除外）。

**排版细节**

- 段落最大宽度：正文 640–720px；文档 620–760px。

## 4. 间距与栅格

4px 基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72 / 104`。

| 场景 | 值 |
| --- | --- |
| 应用外壳内边距 | 32px（移动端 18px） |
| 卡片内边距 | 18–24px |
| 卡片间距 | 12–16px |
| 表单字段间距 | 14–16px |
| 页面区块间距 | 28–40px（展示页 104px） |
| 页面最大宽度 | 1320px |

**Web 应用栅格**

- 侧栏 232px（可收起为 72px 图标轨：右侧 tooltip、计数圆点、顶栏展开按钮）；顶栏 60px。
- 内容区：`1fr`；详情页 `1fr + 296–322px`（主内容 + 上下文栏）。
- 列表页：全宽卡片；看板 6 列，每列最小 168px，横向滚动。
- 表单页：`1fr + 306px`（表单 + 辅助面板），窄屏降级为单列。

## 5. 圆角、阴影与描边

| Token | 值 | 用途 |
| --- | --- | --- |
| `--r-xs` | 5px | 标签、小按钮 |
| `--r-sm` | 7px | 按钮、输入框、树节点 |
| `--r-md` | 10px | 列表卡、弹层 |
| `--r-lg` | 14px | 主卡片 |
| `--r-xl` | 18px | 大面板 / 展示区 |
| `--r-full` | 999px | 状态 pill、头像 |

阴影只三档：

```css
--shadow-1: 0 1px 2px rgba(22,24,28,.04), 0 1px 3px rgba(22,24,28,.03);
--shadow-2: 0 2px 6px rgba(22,24,28,.04), 0 12px 32px -12px rgba(22,24,28,.14);
--shadow-3: 0 24px 64px -20px rgba(22,24,28,.22);
```

- 卡片默认 `shadow-1`；hover 用 `shadow-2`；抽屉 / 弹窗 `shadow-3`。
- 1px `--line` 是主要层级手段；**不要**用双边框或大量阴影堆叠。

## 6. 图标

- 线性图标，24×24 viewBox，`stroke-width: 1.6`，圆角线帽。
- 默认 14–16px；小按钮 12–13px；空状态 18px。
- 图标不单独承载语义：必须配文字或 `aria-label` / tooltip。
- 图标集：[`assets/icons.js`](../assets/icons.js)（约 120 个内联 SVG，无外部请求）。

## 7. 组件规范

### 7.1 按钮

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| Primary | 墨色实心（或蓝色实心） | 页面唯一主操作 |
| Secondary | 白底描边 | 次要动作 |
| Ghost | 无底无框 | 取消、次级链接 |
| Danger | 红字 / 红描边 | 驳回、解除绑定 |
| Small | 28px / 10–11px | 表格与卡片内操作 |
| Icon | 32×32 | 图标动作，必须有 tooltip |

状态：hover 变浅底、active 下移 0.5px、loading 用中心 spinner 替换文字、disabled 45% 透明且不可点击。

### 7.2 状态标签（Pill）

```
● 已通过    ● 待确认    ● 进行中    ● 失败    ● 待上线
```

- 高度 22px（大号 26px），圆角 full；背景 tint + 深色文字 + 6px 圆点。
- 状态文字用业务语言（「待确认」而不是 `in_review`）；工程状态可在 tooltip 中给出。
- 同一语义在任何页面使用同一颜色，例如「待确认」永远是 amber。

### 7.3 输入与表单

- 高度 34px（大号 40px），圆角 7px，边框 `--line-2`。
- 焦点：蓝色描边 + 3px 蓝色 tint 外发光；错误：红色边框 + 不可只靠颜色，附文字。
- 标签与控件间距 6px；支持 hint / 字符计数 / 必填星号。
- 多选负责人：选中 chip + 可搜索下拉；chip 可单独移除。

### 7.4 卡片

- 白底、1px 边框、14px 圆角、`shadow-1`。
- 结构固定：`card-head`（标题 + 动作）→ `card-body` → 可选 `card-foot`（次级信息，浅底）。
- 点击整卡跳转时，hover 位移不超过 1px，边框加深，箭头右移 2px。

### 7.5 表格

- 表头：10.5px 全大写、`--ink-3`、`--surface-2` 底、底部 1px 线。
- 行高 44–56px；hover 用 `--surface-3`；选中行用 `--blue-tint`。
- 强字段用 570 字重 + `--ink`；ID / 时间 / 数值用 mono。
- 一行只放一个主链接；其余动作收进「更多」。

### 7.6 阶段推进器

| 变体 | 用法 |
| --- | --- |
| `stepper`（横向 6 步，带节点与说明） | 需求详情顶部 |
| `stage-rail`（6 段细条） | 列表行、卡片内 |
| `wizard-steps`（带编号与副标题） | 新建需求 |
| `progress`（单条） | Agent 运行、队列数值 |
| `ring`（环形） | 单个百分比（预留） |

规则：已完成 = 墨色实心 + 勾；当前 = 蓝色 + 呼吸点；未来 = 线框 + 灰字。推进动画只播一次（进入页面时），不循环。

### 7.7 文档评审

- 文档正文 12.5–14px，行高 1.75；H2 17–19px，带 hairline 上分隔。
- 行内批注：琥珀色下划线 + 数字 pin；点击联动右侧批注卡。
- 版本对比：`ins` 绿色底、`del` 红色删除线；只显示差异段，不做整页红色。
- 门禁检查：`is-ok` 绿、`is-warn` 琥珀；在门禁条里显示「检查通过 2/3」而不是只显示色块。

### 7.8 图表与监控

- 折线：1.5px 描边，无网格；面积填充 50% tint。
- 迷你进度条：3–5px 高，圆角 full。
- 队列指标：数值 + 单位（小号）+ 一句趋势说明；不要只用红绿。
- Live 指示：小圆点脉冲 + 文字（`运行中` / `实时` / `在线`），1.8–2.4s 周期。

### 7.9 Markdown 文档与批注

- 文档格式固定为 Markdown；界面提供「预览 / 源码」切换，源码以只读 mono 面板展示。
- 批注以行内 pin + 右侧批注卡呈现；未解决批注可作为「交给 AI 生成新版本」的输入。
- 生成新版本不覆盖旧版本；版本历史在左侧栏可见。
- 批注高亮使用琥珀色，不使用红色（红色只表示失败 / 危险）。

### 7.10 浮层

| 类型 | 规范 |
| --- | --- |
| 通知抽屉 | 460px；标题 + tabs + 列表 + 底部设置入口 |
| 详情抽屉 | 620px；用于工单 / 队列 / 调用详情 |
| 命令面板 | 620px，置顶 12vh；输入 + 分组结果 + 键盘提示 |
| 确认弹窗 | 520px（宽 680px）；标题 + 说明 + 主体 + 右对齐按钮 |
| Toast | 墨色底，居中底部，2.4s 自动消失；只用于操作确认 |

遮罩：`rgba(22,24,28,.26)` + 2px 模糊；抽屉/弹窗出现 220–360ms。

### 7.11 权限态与管理组件

| 组件 | 规范 |
| --- | --- |
| 只读条 | 琥珀底 + 单行说明 + 右侧「切换到 SAP IT 视角」；位于页头下方，不遮挡内容 |
| 守卫页 | 居中卡片：图标 + 「当前视角不可用」+ 一句归属说明 + 切换视角 / 返回工作台 |
| 无权限页 | 与守卫页同构：图标 + 「需要管理员权限」+ 原因 + 返回工作台 / 个人设置 + 联系人；不显示任何管理数据 |
| 待处理条 | 白底琥珀描边，逐条：图标 + 标题 + 说明 + 单个动作；只在管理控制台「小组与成员」tab 顶部出现 |
| 成员操作列表 | 弹窗内纵向列表；可用项 hover 变色，不可用项灰显并附原因（最后一名管理员 / 仅平台管理员） |
| 集成状态卡 | 5 态：已连接 / 同步中 / 需处理 / 已停用 / 未配置；需处理卡片带琥珀底与错误摘要，主动作随状态变化 |
| 维护抽屉 | 复用详情抽屉 620px：连接信息 / 凭据 / 健康 / 最近调用 + 底部危险动作；动作全部写审计 |
| 二级视图切换 | 管理控制台「集成与维护」tab 内的 segmented：「连接与凭据 / 小组参数」；同一时间只显示一个子视图，切换保留当前小组 |
| 参数 chips | 参数表默认值 chip 用「字段名 + 本组有效值」，不只靠颜色：已覆盖 = 蓝底蓝字，继承 = 灰底灰字；来源列用 pill 给「已覆盖 N 项 / 继承平台默认」 |
| 审计表 | 顶部类型 chips + 6 列表格；结果列用语义 pill；不可编辑 |

规则：

- 无权限的**入口**隐藏（不占位）；目标受限的**动作**禁用并附原因，两者不混用。
- 只读态保留查看能力，不出现「看得见点不动」的写按钮。
- 管理动作必须有结果反馈：状态回写 + toast + 审计，不能只弹提示。

## 8. 动效

动效只解释三件事：**进入、状态变化、因果与层级**。不做装饰、不做滚动劫持、不做无限循环（状态指示除外）。

### 8.1 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dur-1` | 140ms | hover、按压、颜色 |
| `--dur-2` | 220ms | 展开 / 收起、面板切换、toast 离场 |
| `--dur-3` | 360ms | 抽屉、弹窗、页面淡入 |
| `--dur-4` | 560ms | 区块入场 |
| `--dur-5` | 900ms | 数字滚动、阶段线/进度填充 |
| `--dur-exit` | 120ms | 路由离场（JS 与 CSS 共用同一个值） |
| `--stagger` | 38ms | 同屏子元素交错步长（最多 8 个） |
| `--ease` | `cubic-bezier(.22,.72,.24,1)` | 默认 |
| `--ease-out` | `cubic-bezier(.16,1,.3,1)` | 入场、位移动画 |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 离场、收起 |
| `--ease-spring` | `cubic-bezier(.34,1.4,.5,1)` | 仅成功勾选 / switch |

### 8.2 四层动效

| 层 | 动效 | 入口 |
| --- | --- | --- |
| 页面 | 进入 `fade 360` + 直接子元素 `rise 560` 交错 38ms（上限 8）；离场 `fade-out 120` | `assets/app.js` `render()`、`assets/app.css` |
| 区块 | 列表 / 面板 / tab 内容切换 `fade 220`；保存、状态回写后一次 `rise` | 页面 JS 复用 `.anim-fade` / `.anim-rise` |
| 组件 | 抽屉滑入 360、弹窗 scale+fade、toast、按钮 loading、switch、tab 下划线缩放 | `assets/components.css` |
| 数据 | 数字 900ms 计数、进度条填充、sparkline 描线 | `SA.countUp` / `SA.animateBars` |

唯一允许的循环：状态指示（live dot 呼吸、loading spinner、队列事件流、展示页 hero / marquee）。

### 8.3 运行时 API（`assets/app.js`）

| API | 用途 |
| --- | --- |
| `SA.after(fn, ms)` | 一次性延时，登记在 `SA.timeouts`，路由切换统一清理、触发后自动出队；时长与 token 对齐（`SA.dur("--dur-3")`） |
| `SA.sequence(fn, ms)` | 演示序列延时：`reduced-motion` 下压缩到 ≤ 80ms；`?shot=1` 时页面自己跳过序列 |
| `SA.later(fn, ms)` | 不随路由清理的一次性延时（toast 自动消失、外壳动效） |
| `SA.dur(token)` | 读取 token 的毫秒数，避免 JS 写死 |
| `SA.isReducedMotion()` | reduced-motion 检测 |
| `SA.scrollTop({ smooth })` | 回到顶部；smooth 在 reduced-motion 下自动降级为直接跳转 |
| `SA.onTimer(fn, ms)` / `SA.offTimer(id)` / `SA.clearTimers()` | 循环计时器：登记、单独停表（暂停态）、路由切换全清 |

规则：

- 新增代码不再出现裸 `setTimeout` / `setInterval`；页面序列用 `SA.after` / `SA.sequence`，外壳行为用 `SA.later`。
- 不把 `animationend` / `transitionend` 作为状态唯一来源：reduced-motion 下时长为 0.001ms。
- 交错只作用于页面直接子元素和首屏列表，最多 8 个，避免长列表尾部延迟。
- 过渡只写具体属性，不写 `transition: all`；hover 位移 ≤ 2px；tooltip 只做 opacity + 1–4px 位移，不加进入动画。
- 新动效必须 2.2s 内收敛（截图脚本 `--virtual-time-budget=2500`，取更严的值）。

### 8.4 三种模式

| 模式 | 行为 |
| --- | --- |
| 正常 | 按 token 播放 |
| `prefers-reduced-motion: reduce` | `--dur-*` / `--stagger` 归零，全局 animation / transition / delay 压到 0.001ms；JS 序列等待压缩 |
| `?shot=1` | `html.shot-mode` 关闭全部 animation / transition；JS 直接写终值、跳过序列 |

改动动效后先跑 `node scripts/motion-audit.mjs`（19 项三模式断言），再跑截图脚本。

## 9. 响应式

| 断点 | 行为 |
| --- | --- |
| ≥ 1180px | 完整双栏 / 三栏 |
| 960–1180px | 侧栏保留 232px；详情侧栏下沉为两列；看板横向滚动 |
| ≤ 960px | 侧栏变为抽屉（顶栏菜单按钮）；隐藏次要列；内边距 18px |
| ≤ 640px | 单栏；表格横向滚动；抽屉全宽；字体缩小一档 |

原则：**先隐藏辅助信息，不隐藏操作。** 表格在窄屏可以横向滚动，不折叠成卡片迷宫。

## 10. 可访问性

- 正文对比度 ≥ 4.5:1；辅助文本至少 3:1；不使用纯色块承载唯一含义。
- 所有交互控件有可见 focus ring（2px 蓝 + 2px offset）。
- 图标按钮必须有 `aria-label`；状态变化通过 `aria-live="polite"` 区域播报。
- 表单标签与控件用 `for/id` 关联；错误信息紧邻字段。
- 键盘：`⌘K` 命令面板、`Esc` 关闭浮层、`Tab` 顺序符合视觉顺序、命令面板支持 ↑↓/Enter。
- 尊重 `prefers-reduced-motion`；不使用纯手势操作。

## 11. 实现约定

- 所有颜色、字号、间距、圆角、时长均通过 CSS 变量引用，禁止在页面内写死色值（演示数据中的品牌色除外）。
- 组件类名采用 `block__element--modifier`，状态类 `is-*`（`is-active` / `is-done` / `is-current` / `is-open`）。
- 页面级样式放在 `assets/app.css`（按页面注释分区）；VSCode 模拟器与展示页各自独立 CSS。
- 新增页面时优先复用 `.page-head`、`.card`、`.pill`、`.table`、`.stepper`、`.drawer` 等基础结构，不另起一套。

## 12. 设计走查清单

- [ ] 页面只有一个 Primary 按钮
- [ ] 状态都有文字，不只靠颜色
- [ ] 表格 ID / 时间 / 数字使用 mono
- [ ] 卡片没有多余边框和阴影
- [ ] 长文本行宽 ≤ 760px
- [ ] 空状态给出下一步动作
- [ ] 失败信息说明「现在该做什么」
- [ ] 所有浮层可 Esc 关闭
- [ ] 减少动效模式下内容完整
- [ ] 窄屏关键操作仍可达
- [ ] 无权限：入口隐藏、动作禁用并说明原因
- [ ] 只读态保留查看、隐藏写操作
- [ ] 管理动作有状态回写与审计
